📝 Ejercicio de Clase (Gustavo)

Grilla de productos Mobile-First: 1 columna en celular, 2 en tablet (≥768px), 3 en desktop (≥1024px).

Consigna

  1. Creá una grilla de productos con la clase .grid-container que contenga 3 tarjetas .card
  2. Escribí el CSS base con enfoque Mobile-First: las tarjetas deben ocupar el 100% del ancho de la pantalla y el espaciado debe ser angosto (probá con margin-bottom en cada tarjeta).
  3. Agregá una Media Query con @media (min-width: 768px) para que en tablets las tarjetas se acomoden en dos columnas:
    • En .grid-container, sumá flex-wrap: wrap para que las tarjetas puedan pasar a la fila siguiente en vez de aplastarse todas juntas.
    • En .card, poné width: 48%.
    • En .grid-container, sumá también justify-content: space-between para que el espacio libre se reparta solo entre las tarjetas.
  4. Agregá otra Media Query con @media (min-width: 1024px) para que en pantallas de escritorio las tarjetas se organicen en tres columnas (width: 30% en .card ).
  5. Asegurate de que todas las imágenes dentro de las tarjetas tengan max-width: 100% para que nunca se desborden de su contenedor.

Pista:flex-wrap y justify-content no salieron en los ejemplos anteriores de Flexbox — son las dos propiedades nuevas que necesitás para este ejercicio.
